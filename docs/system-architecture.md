# System architecture

Living list for the public jewel deploy. Change a row when a component is added, removed, or repriced.

Checked 2026-10-06. One Linux VM, one hostname (`tryjewel.dev`), Caddy in front, Postgres and Neo4j Community beside the API. Google sign-in stays in Testing, under 100 named people. The running machine is `VM.Standard.E5.Flex` at 1 OCPU and 8 GB in `ap-hyderabad-1`, public address `150.230.131.57`, paid from trial credit that expires on 2 November 2026. The console estimate is about $50 a month. Terminate the instance and its boot volume before that date, and do not click Upgrade. `.dev` is HTTPS-only in the browser, so the site works only after Caddy has a certificate.

Confirm the registrar and the VM checkout before paying. Model calls are paid by the key typed in the browser, not by this table.
